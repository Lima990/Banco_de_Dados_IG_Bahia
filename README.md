# Banco de Dados de Potenciais Indicações Geográficas da Bahia

## Sobre o projeto

Este repositório disponibiliza a base de dados produzida durante a dissertação de mestrado intitulada:

**Prospecção de Indicações Geográficas na Bahia: Mapeamento por Territórios de Identidade**

O banco reúne os potenciais produtos e serviços com vocação para obtenção de Indicação Geográfica (IG) no Estado da Bahia, organizados por Territórios de Identidade.
